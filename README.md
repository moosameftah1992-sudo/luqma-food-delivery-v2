# لقمة — التشغيل والإدارة

## تشغيل المنصّة

- متغيرات السيرفر المطلوبة: `DATABASE_URL` لقاعدة PostgreSQL، و`SESSION_SECRET` طويل وعشوائي للجلسات.
- لإنشاء حساب المالك `moosameftah` بصلاحية `all` عند تهيئة قاعدة جديدة، اضبط `LUQMA_ADMIN_PASSWORD` بكلمة مرور سرية من **16 حرفاً على الأقل**. `LUQMA_ADMIN_EMAIL` اختياري؛ لا تُكتب كلمة المرور في المصدر. الحساب الموجود لا تُستبدل كلمة مروره عند إعادة النشر.
- رابط الدخول للإدارة موجود في **ذيل** الصفحة الرئيسية، أو مباشرةً `/admin/login`. يمكن الدخول باسم المستخدم أو البريد الإداري المرتبط بالحساب. لا تُنشأ حسابات تجريبية تلقائياً.
- تفعيل تسجيل العملاء والمندوبين يتطلب `RESEND_API_KEY` و`MAIL_FROM` بنطاق بريد موثّق و`APP_URL` بعنوان الموقع HTTPS العام. لا يُفعّل العميل قبل تأكيد البريد، ولا يُفعّل المندوب قبل تأكيد البريد واعتماد الأدمن لوثائقه.
- الدفع الحقيقي بالبطاقة أو BenefitPay عبر صفحة Tap المستضافة يتطلب `TAP_SECRET_KEY` (مفتاح مباشر في الإنتاج) و`TAP_MERCHANT_ID` و`APP_URL`. لا يُرسل طلب غير مدفوع للمتجر. عند غياب الإعداد، يتوقف الدفع برسالة واضحة ولا يُنشأ طلب مدفوع وهمي.
- عند أول اتصال تُنشئ التهيئة الجداول اللازمة بطريقة إضافية داخل معاملة PostgreSQL دون مسح حسابات أو طلبات أو إعدادات CMS. يتطلب الاتصال صلاحية `CREATE` وقراءة/كتابة على المخطط. `/api/health` يُرجع `{"ok":true,"db":"ready"}` عند النجاح.

## Option A: أوقات العمل والتوفر

من **لوحة المتجر ← الحالة** يمكن تبديل الحالة اليدوية فوراً بين **مفتوح / مشغول / مغلق**، وإضافة فترة «من / إلى» واحدة أو أكثر لكل يوم من الأسبوع (حتى ثماني فترات يومياً)، ونسخ فترات يوم إلى بقية الأسبوع أو حذفها. يشمل التحقق الفترات الممتدة بعد منتصف الليل والتداخل بين يومين، وكل الأوقات **بتوقيت البحرين**. اليوم بلا فترات يكون مغلقاً عندما يكون الجدول مفعلاً. إذا كان الجدول فارغاً، يبقى سلوك المتجر اليدوي القديم كما هو. للحالة اليدوية **مشغول/مغلق** الأولوية حتى داخل ساعات العمل.

من **لوحة المتجر ← القائمة** يمكن تحويل كل صنف بمفرده إلى **متوفر / غير متوفر** بدون تغيير سعره. ومن **لوحة الأدمن ← المتاجر ← إدارة التشغيل** يمكن تعديل الحالات والجدول وتوفر كل صنف للمتجر المختار، وفق صلاحيات المستخدمين/العمليات. يظهر الإغلاق خارج أوقات العمل للعميل وتُمنع الطلبات الجديدة خارج المواعيد؛ لا تتأثر الطلبات الموجودة. تتطلب تغييرات أسعار الأصناف موافقة الأدمن كما كانت.

ترحيل `working_hours` إضافة غير هدّامة بعمود JSONB افتراضي `[]`؛ لا يحذف جدولاً ولا يغيّر ساعات متجر موجود ما لم يحفظها صاحب المتجر أو الأدمن.
